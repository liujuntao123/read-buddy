# 04: 显式轮数配额（Turn Quota）伴读对话

**What to build:**
在 AI 伴读侧边栏的“伴读对话”Tab 中构建以当前章节文本为上下文底座的智能问答功能。拒绝隐蔽的后端滑动窗口截断，采用用户显式可见的轮数配额机制（默认 10 轮问答），在输入框上方提供动态进度胶囊；当配额用尽时友好提示并引导开启新话题，历史对话完整归档并支持多会话检索。

**Blocked by:** 01 (双栏布局分屏容器与 AI Provider 配置中心), 03 (严格手动触发与超长章节 Map-Reduce 结构化总结)

**Status:** ready-for-agent

### Acceptance Criteria

- [ ] 对话上下文自动注入当前章节文本与 System Prompt（防剧透约束：除非用户明确要求透露后续，严禁提前剧透）。
- [ ] 界面输入框上方展示轮数配额胶囊（例如：`💬 3 / 10 轮`），单次问答成功后轮数自动 +1。
- [ ] 当前话题内的所有历史消息在未达配额前 100% 完整送入模型上下文，不进行隐蔽的静默截断。
- [ ] 当达到配置的上限（10/10 轮）时，输入框禁用，转为提示：*“本轮话题探讨已达上限（10/10），建议开启新话题以保持解答精准度”*。
- [ ] 满额后界面提供显著操作入口：`[ ➕ 开启新话题 ]` 与 `[ 📋 导出/复制本轮对话 ]`。
- [ ] 支持按书籍切换或查看以往的历史对话话题列表，点击历史项可回溯完整问答记录。
- [ ] 单元测试验证对话流式状态、Turn Quota 递增与锁定机制、以及上下文 Prompt 拼装边界。
