# 05: 原生选区标注栏 AI 快捷菜单融合与端到端回归

**What to build:**
将划词选区 AI 快捷操作（解释、翻译、追问、提炼）有机融入 Foliate/Readest 原生选区浮动标注栏，避免双弹窗冲突，点击追问时自动将选区作为 Blockquote 填入伴读对话框并聚焦光标；同时完成宽窄屏响应式（宽屏双栏 / <768px 抽屉模式）及全套端到端回归验证。

**Blocked by:** 04 (显式轮数配额伴读对话)

**Status:** closed

### Acceptance Criteria

- [x] 监听正文选区高亮事件，在原生 `AnnotatorToolbar`（高亮/下划线/笔记）旁扩展 AI 动作组：[💡 解释]、[🌐 翻译]、[💬 追问]、[📝 提炼]。（demo 阅读器以独立浮动工具栏实现；注入 Foliate 原生标注栏待 Foliate 接入，ADR 0007 目标不变）
- [x] 点击阅读器空白处时，工具栏和选区平滑收起消失，无视觉撕裂与残留。
- [x] 点击“💬 追问”时：若 AI 侧边栏处于折叠状态，自动展开侧边栏；激活“伴读对话”Tab；将选中文本自动以 `> 选中文本` 引用格式填充至输入框，并将输入焦点置入末尾。
- [x] 点击“💡 解释”或“🌐 翻译”时，在侧边栏快速以预设 Prompt 发起问答。
- [x] 视窗宽度 $< 768px$ 时，双栏自动折叠转换为抽屉模式（Drawer/Sheet），保证正文阅读排版不被挤压。
- [x] AI 侧边栏各元素的背景色、文字颜色与高亮完全适配日间白、羊皮纸黄和深色暗黑主题。
- [x] 编写端到端组件测试，验证选区唤起、引用填充与响应式断点表现。
