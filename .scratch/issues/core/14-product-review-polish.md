### Problem

一次完整的产品评审（审美 / 功能 / 体验）发现的缺口，按用户旅程排序：

**阅读（主视窗）**
1. 没有任何阅读进度感知。评审时那份设计文档 §3 的 FooterBar（章节名、百分比、快速跳转）完全缺失；
   引擎已经在 relocate 里给出 `fraction`、也有 `goToFraction`，却没人用。
2. ReaderDock 只在鼠标移入右下角时出现，首次打开书的读者根本不知道目录与排版设置在哪。
3. 打开引擎书籍时，`openIn` 完成前阅读区是一片空白，没有加载态。
4. TXT / 分段书读到一节末尾是死路：必须去找隐藏的 dock 才能进入下一节。
5. 护眼主题的书内链接是紫色 `#8b5cf6`，与羊皮纸暖色调冲突。

**AI 伴读（侧栏）**
6. 错误直接展示 SDK 原始 message（常为英文堆栈式文案），没有按当时设计文档 §6 分类
   （网络 / Key 无效 / 429 限流 / 模型不存在 / 余额），也没有「去设置」按钮——只有一句
   「请在侧栏右上角 ⚙ 检查」。对话出错只有一行被截断的红字，没有重试。
7. 未配置模型时没有引导：点了「总结当前节」或发出第一个问题才报错。
8. 对话空状态只有一行灰字，没有示例问题，AI 能做什么完全靠猜。
9. 单条回答无法复制；「复制对话」只在配额耗尽时出现。
10. 总结生成后无法复制。
11. 「📍 定位到原文」emoji 与 MapPin 图标重复；章节标题被套上书名号《》
    （《》只用于书名，章节名不该用）。

**书架**
12. 没有「继续阅读」主入口：最重要的动作藏在 Header 的一个图标按钮里。
13. 每张封面常驻一个删除 ×，视觉噪音大且容易误触；阅读进度只是一行小字，
    没有直观的进度条。
14. 书架模式下 Header 左上角品牌图标是一个什么都不做的按钮。

**划线**
15. 划线只能跳转和删除：不能拿一条划线去问 AI，也不能导出/复制全部划线。

### Acceptance Criteria

- [x] 阅读区有安静的进度条（节点标题 + 百分比，可点击/拖动跳转），TXT 与引擎书籍都有。
      （落成时在阅读区**顶部**，见 ticket 15 的边界调整；组件 `ReaderProgressBar`。）
- [x] 打开书籍时 dock 短暂显现一次再隐去；阅读区有加载态。
- [x] TXT 一节读完有「下一节」入口。
- [x] 护眼主题链接为暖色。
- [x] AI 错误统一分类为可读中文，总结与对话均提供「重试」「打开 AI 设置」。
- [x] 未配置模型时，总结 / 对话面板给出配置引导卡片。
- [x] 对话空状态提供可点击的示例问题；每条回答可复制；总结可复制。
- [x] 书架顶部有「继续阅读」卡片；删除按钮仅悬停/聚焦时出现；封面带进度条。
- [x] 划线列表每条可「问 AI」，并可一键复制全部划线为 Markdown。
- [x] `pnpm typecheck && pnpm test` 全绿。
