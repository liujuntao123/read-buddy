# Domain Glossary: readest-plus

This document defines the ubiquitous language for the `readest-plus` project. All specifications, ADRs, tickets, and code implementations must adhere strictly to these term definitions.

---

### Book
An electronic publication (e.g., EPUB, MOBI, PDF, TXT) ingested and rendered by the client, uniquely identified across sessions by a deterministic content hash (`bookHash`).

### Section / Chapter
A discrete spine unit or navigable boundary within a Book, referenced by a 0-based ordinal (`sectionIndex`) and its textual heading (`chapterTitle`).

### Virtual Section (虚拟章节)
A synthetic section boundary dynamically partitioned by the client for unformatted or monolithic books (e.g., single-spine TXT, unbroken EPUBs) based on regex chapter heuristics or length-based chunking rules.

### Segmentation Rule (分段规则)
The strategy used to determine chapter boundaries for books lacking structured TOCs. Includes automatic pattern matching (e.g., `第X章`, `Chapter N`), fixed-word splitting, or user-guided custom configuration.

### Reading Context
The reactive, live state representing the reader's current progress through a Book. It encompasses the active `bookHash`, `sectionIndex` (or `virtualSectionIndex`), chapter label, page information, and EPUB CFI location.

### Chapter Summary
A structured distillation of a single Section's text generated by an AI Provider upon explicit reader trigger. It consists strictly of three standardized sections: Core Takeaway, Content Outline, and Key Concepts. A Chapter Summary is uniquely cached and keyed by `${bookHash}:${sectionIndex}`.

### Map-Reduce Summarization (两阶段分块汇总)
A summarization pipeline for chapters exceeding the model context or optimal summarization token threshold: the text is chunked into logical sub-blocks, distilled individually (Map), and synthesized into the final three-part structured summary (Reduce).

### Text Selection
A continuous fragment of textual content explicitly highlighted by the user within the main reading view.

### Floating Action Toolbar
A contextual floating overlay rendered immediately adjacent to an active Text Selection, exposing instant actions: Explain, Translate, Summarize, and Ask AI.

### AI Companion
The persistent, collapsible, resizable right-hand sidebar operating in split-screen configuration alongside the main reading viewport. It hosts the Chapter Summary panel and the Interactive Chat panel.

### AI Provider
An external or local LLM service implementing OpenAI-compatible HTTP streaming protocol (e.g., DeepSeek, OpenAI, Anthropic via proxy, Ollama, vLLM). It supplies chat completion and text streaming capabilities.

### Conversation
An ordered sequence of interactive prompt-response turns between the reader and the AI Companion, scoped to a Book and bounded by an explicit Turn Quota.

### Turn Quota (对话轮数上限)
An explicit, user-visible cap on the number of question-and-answer pairs within a single Conversation topic. When exhausted, the reader is prompted to start a fresh topic to keep context dense and prevent conversational drift.
