# Domain Glossary: readest-plus

This document defines the ubiquitous language for the `readest-plus` project. All specifications, ADRs, tickets, and code implementations must adhere strictly to these term definitions.

---

## Book structure

**Book Node (书籍节点)**:
One navigable, text-bearing division of a Book, identified by its 0-based document-order ordinal (`nodeIndex`) over the book's global continuous character space. Every count, ordinal, breadcrumb and navigation label in the app is about book nodes.
_Avoid_: chapter (as a word for any division), section (as an English synonym for any division), passage, unit, item

**Chapter (章)**:
A book node at the **first level** — a division directly under the Book.
_Avoid_: part, volume, book-part (those are a Book's own *titles* for a 章, not a different concept)

**Section (节)**:
A book node at the **second level** — a division nested under a Chapter.
_Avoid_: subsection, sub-chapter, sub-node

**Chunk (段)**:
A book node synthesized by fixed-length segmentation for a Book that declares no usable structure. It behaves as a first-level node but must never be described as a 章.
_Avoid_: virtual chapter, fake chapter, page

**Minimal Node (最小节点)**:
The deepest node level a Book actually has: the 节 of a 章/节 book, the 章 of a single-level book, the 段 of a structureless book. It is the viewpoint of every summary, micro-brief and companion index.
_Avoid_: leaf, smallest section, current chapter, "本节" used loosely

**Book Node Shape (节点形状)**:
The composition of a Book's nodes — how many 章, 节 and 段 it contains, and therefore which level is its Minimal Node. Every "N 章 · M 节"-style phrase is derived from it.
_Avoid_: chapter count, TOC stats

**Spine Section (物理段)**:
The physical container a Book's file is cut into (an EPUB spine item, a TXT virtual segment). A carrier for book nodes, not a domain node itself: one spine section may hold several nodes, and a node may span several spine sections.
_Avoid_: chapter, section, node

**Directory (目录)**:
The Book's own declared navigation tree (EPUB NCX or nav document), with its own nesting depth and, optionally, intra-section anchors. It is the **preferred source of book nodes** — nodes follow it whenever it describes the Book more finely or more coarsely than the physical spine does.
_Avoid_: outline (that is the companion agent's rendering of the node list), TOC page (a printed contents page inside the text)

**Node Anchor (段内锚点)**:
A Directory destination *inside* a spine section. It is what makes a 节 a node with a text range of its own rather than a marker on a flat list.
_Avoid_: bookmark, link target

## Reading

**Book**:
An electronic publication (e.g. EPUB, MOBI, FBZ, TXT) ingested and rendered by the client, uniquely identified across sessions by a deterministic content hash (`bookHash`).

**Reading Position (阅读位置)**:
The reader viewport's **physical** location: the spine-section ordinal plus, when the viewport sits inside an anchored node, that node's anchor. It is deliberately *not* a node ordinal — the node is derived from it.
_Avoid_: current chapter, section index

**Reading Context**:
The reactive, live state representing the reader's current progress through a Book. It encompasses the active `bookHash`, the Reading Position, that position's title, and the EPUB CFI location.

**Node View (节点视图)**:
The Book Node the reader is currently at, resolved from the Reading Position together with everything a surface needs to speak about it: its 0-based global ordinal, its title, its level (章 / 节 / 段), its parent 章 title, its character count and its text. It is the single answer to 「读者此刻在哪一个 Book Node」.
_Avoid_: current chapter, current node, node context, node source, node hierarchy (all four name a *part* of a Node View, or an older private name for one — a 节 is not a 章, and "current" alone never says whether the physical or the logical ordinal is meant)

## Summaries and the companion agent

**Node Summary**:
A structured distillation of a single **Minimal Node**'s text generated by an AI Provider upon explicit reader trigger. It consists strictly of three standardized parts: 核心要义, 关键内容脉络, and 核心概念与关键术语. A Node Summary is uniquely cached and keyed by `${bookHash}:${nodeIndex}`.

**Map-Reduce Summarization (两阶段分块汇总)**:
A summarization pipeline for minimal nodes exceeding the model context or optimal summarization token threshold: the text is chunked into logical sub-blocks, distilled individually (Map), and synthesized into the final three-part structured summary (Reduce).

**Reading Agent Index (伴读索引)**:
The whole-Book preparation the companion agent runs at import time: the Book Node list, the per-minimal-node micro-brief, and the whole-Book panorama. Container 章 are never briefed. Its two halves are separate operations: **Book Ingestion** (the Book Node list, no model involved) and the model-dependent half (the panorama, then the micro-brief queue), which reports its progress and settles so a caller can await the Book being prepared rather than poll for it.
_Avoid_: indexing (that word is also the reader's segmentation phase), embedding index (there is none — see ADR 0002)

**Book Ingestion (书籍导入编排)**:
The half of 伴读索引 that needs no model: resolve a Book's text, derive its Book Nodes (`段` / `章` / `节`), and persist them with the **Segmentation Rule** that produced them. It runs on every Book open and owns the global continuous character space — the join that the "offsets index the joined text" invariant depends on.
_Avoid_: import (that is putting a file on the shelf), parse (that is one source adapter inside it)

**Micro-Brief (节点微大纲)**:
A 50~100 character objective digest of one **Minimal Node**, generated at import time from that node's head and tail slices.

**Book Panorama (全书全景画像)**:
The whole-Book portrait — genre, theme summary, world setting, main characters — synthesized in one model call over the Book Node outline and the opening/closing slices.

**Text Selection**:
A continuous fragment of textual content explicitly highlighted by the user within the main reading view. It is captured by one set of rules (minimum length, gesture events, containment) shared by both places it can occur: the host reading article and a chapter's own document inside the engine's iframe.
_Avoid_: highlight (that is the reader's visual mark), quote (that is the fragment as it travels into a prompt), selection range (that is the DOM primitive)

**Highlight (划线)**:
A reader-made mark over a Text Selection, kept until the reader deletes it and painted again every time its chapter is displayed. It is identified by the Book Node it was made in plus a **text anchor** — the quoted text with its surrounding context — because the rendering engine rebuilds a chapter's document on every chapter change; it is not identified by a DOM offset, a Range or a CFI.
_Avoid_: annotation, note, bookmark (all three mean something the reader edits or navigates by, not a mark over text), agent highlight (that is the transient breathing cue `locate_in_reader` produces, which clears itself)

**Highlight Anchor (划线锚)**:
The quoted text of a Highlight together with a short prefix and suffix from the same document. Whitespace is ignored when matching, because a selection that spans two paragraphs carries a block separator the rendered text does not have. The context is what tells two identical sentences in one chapter apart.
_Avoid_: offset, coordinate, position (positions are the Reading Position's vocabulary, in a different coordinate space)

**Floating Action Toolbar**:
A contextual floating overlay rendered immediately adjacent to an active Text Selection, exposing instant actions: Explain, Translate, Summarize, and Ask AI.

**Chapter Navigation**:
The single rule that answers 「下一章 / 上一章」 for any Book: a step moves in **document order** through the Book's Directory rows, skipping rows that point at the position the reader is already at. Its two Adapters differ only in *where* a row goes — a Directory href for an engine book, a virtual-section ordinal for a segmented book — never in the rule.
_Avoid_: page turn (that is `next`/`prev`, which stay inside a chapter), scroll (that is the viewport, not navigation)

**AI Companion (伴读)**:
The persistent, collapsible, resizable right-hand sidebar operating in split-screen configuration alongside the main reading viewport. It hosts the Node Summary panel and the Interactive Chat panel.

**AI Provider**:
An external or local LLM service implementing OpenAI-compatible HTTP streaming protocol (e.g. DeepSeek, OpenAI, Anthropic via proxy, Ollama, vLLM). It supplies chat completion and text streaming capabilities.

**Conversation**:
An ordered sequence of interactive prompt-response turns between the reader and the AI Companion, scoped to a Book and bounded by an explicit Turn Quota.

**Turn Quota (对话轮数上限)**:
An explicit, user-visible cap on the number of question-and-answer pairs within a single Conversation topic. When exhausted, the reader is prompted to start a fresh topic to keep context dense and prevent conversational drift.

**Segmentation Rule (分段规则)**:
The strategy used to determine Book Nodes for Books lacking a Directory. Includes automatic pattern matching (e.g. `第X章`, `Chapter N`), Directory anchors, or length-based chunking.

## Presentation and the reading engine

**Presentation**:
Everything about how the Book's text *looks* rather than what it says: the Reading Theme, the reader's typography, and the page geometry (page mode, column width, margins, column gap). It is applied to the engine through one operation, and whether the underlying rendering engine can honour a given knob is reported by the engine, never probed by its callers.
_Avoid_: style, theme (that is one input to Presentation), layout (that is only its geometry half)
