# Triage Label Vocabulary

This repo uses the five canonical triage roles with 1:1 label strings:

| Role | Label string | Meaning |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | Newly arrived, unprocessed issue |
| `needs-info` | `needs-info` | Blocked waiting for external response or user clarification |
| `ready-for-agent` | `ready-for-agent` | Fully specified, actionable by an AI agent |
| `ready-for-human` | `ready-for-human` | Needs physical hardware, external credentials, or manual evaluation |
| `wontfix` | `wontfix` | Decided against building or out of scope |
