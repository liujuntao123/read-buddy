# 概念地图与阅读体验

## 从总结继续探索

概念地图位于辅助边栏的「总结」中，由当前总结的核心要义、关键内容脉络、核心概念组成。生成或更新总结后，地图同步更新，不再单独调用 AI。已有总结可直接查看地图；重新生成期间保留上一份完整地图。

- 总结每个部分的「在概念地图中查看」定位对应分支；节点详情中的「查看对应总结」展开并聚焦原来的文字部分。
- 单击节点先预览完整内容。节点右侧 + / − 折叠分支，工具栏支持展开全部、显示关联、搜索大纲和复制。
- 实线表示总结的组织层级；虚线「涉及」仅表示要义或脉络中明确提到了某个核心概念，不推测因果关系。
- 只有在本节点正文中能唯一匹配的引文才显示「查看原文」。点击后通过阅读器统一导航定位；无法核验的提炼表述保留总结入口。
- 「追问这个概念」把总结表述和已核验依据带入伴读引用框，读者编辑问题后再发送，不自动请求模型。
- 拖动平移、滚轮缩放，也可使用缩放、查看全图、聚焦选中概念按钮。选中节点不会重置视角。
- 「放大地图」打开独立工作区，图形与详情并排；窄屏改为上下排列。侧栏与弹窗保留搜索、选择、折叠状态。
- 文字大纲可搜索已折叠的内容，键盘也可选择条目。复制得到完整 Markdown 大纲，不受当前折叠或搜索影响。

地图随总结保存在本地；图形是可重建的视图。数据库 v9 的 `concept_maps` 表保留用于兼容早期独立地图缓存，新界面不再读写该缓存。删除书籍并选择删除相关资料时仍会清理它。

## 贯穿阅读流程的入口

| 功能 | 使用方式 |
| --- | --- |
| 接下来读 | 点击书封或列表上的书签加入清单；书架可筛选全部、接下来读、已开始、未开始 |
| 书架偏好 | 排序、网格/列表视图、阅读清单保存在本机；清单不会改变阅读位置 |
| 搜索与快捷操作 | 顶栏搜索按钮或 Ctrl / ⌘ + K；搜索藏书、功能与当前书的原文 |
| 原文搜索 | 输入至少两个字符，匹配原文，最多展示 12 处；上下键选择，Enter 定位，不消耗 AI 调用 |
| 专注阅读 | 顶栏专注按钮或 Ctrl / ⌘ + Shift + F 隐藏导航与伴读；Esc 或「退出专注」恢复原布局 |
| 划线检索 | 搜索引文或位置，查看匹配数量，再定位原文或带入伴读 |

专注模式保留阅读器实例；刷新后回到常规布局。书架的「已开始」表示存在阅读位置，不根据最后一个节点推断整本书已经读完。书架搜索只查藏书标题和作者；全局入口的原文检索只查当前打开的书，不跨书下载或请求模型。

## 实现

- `services/summary/summaryStructure.ts`：总结结构解析，文字与地图共享。
- `services/conceptMap/summaryMap.ts`：总结投影、引用核验、显式概念提及关系。
- `components/sidebar/ConceptMapPanel.tsx`：联动、详情、搜索、原文导航、伴读追问。
- `components/sidebar/ConceptGraph.tsx`：G6 节点、视角、主题与生命周期。
- `components/WorkspaceCommands.tsx`：搜索与快捷操作，复用原文索引和 `readerLink`。
- `store/workspaceUIStore.ts`：书架偏好与临时专注状态。

总结仍是模型的提炼，地图帮助浏览和核验，不把模型表述当作原文证据。
